== HOW TO USE ==
- Create a callout using [!litm-danger]
- Inside it #### (h4) will create a subtitle
- ## (h2) will create titles, but you can also use sections with [!litm-section]+ if you want them foldable
- [!litm-columns] will add the 2 first items under it inside the left collumn, and the third inside the right collumn
- The highlights color are changed for the correct one for the yellow, red and green one. To have the grey one (like inside threats & conséquences) you have to use purple highlight.
- Inside the callout separation lines using --- will create the gradient one
